Bienvenido a ZelixOS
===================

ZelixOS es una distribución basada en Arch Linux. Zelix Hello reúne aplicaciones,
controladores, actualizaciones y ajustes básicos del sistema.

Paquetes y actualizaciones
-------------------------
Actualizar todo el sistema:
  sudo pacman -Syu

Instalar una aplicación manteniendo el sistema actualizado:
  sudo pacman -Syu nombre_del_paquete

Para paquetes del AUR puedes usar Paru o Yay. Revisa el PKGBUILD antes de instalar.
Las aplicaciones Flatpak se gestionan mediante Flatpak y Flathub.

Herramientas Zelix
-----------------
- Zelix Hello: aplicaciones, controladores y herramientas del sistema.
- Zelix Updater: actualizaciones de los repositorios configurados en pacman.
- Zelix CLI: ejecuta zelix help para consultar los comandos disponibles.

Idioma
------
Selecciona English, Türkçe o Español en Zelix Hello. La preferencia se guarda para
las siguientes sesiones. Los mensajes de herramientas externas pueden usar el
idioma configurado por esas herramientas.
